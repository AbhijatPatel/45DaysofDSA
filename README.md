#45-Day DSA Challenge 🚀

Welcome to my 45-Day Data Structures & Algorithms (DSA) Challenge! This challenge is designed to build strong problem-solving skills, master core DSA concepts, and prepare for coding interviews and campus placements.

🎯 Goals

- Solve DSA problems consistently for 45 days.
- Strengthen understanding of data structures and algorithms.
- Improve coding speed, accuracy, and logical thinking.
- Prepare for coding rounds on platforms like LeetCode, GeeksforGeeks, and CodeStudio.

📚 Topics Covered

- Arrays
- Strings
- Searching & Sorting
- Recursion & Backtracking
- Linked Lists
- Stacks & Queues
- Hashing
- Trees & Binary Search Trees
- Heaps
- Graphs
- Greedy Algorithms
- Dynamic Programming
- Tries
- Bit Manipulation

💻 Language

- C++

🛠️ Challenge Rules

- Solve at least 2–5 problems every day.
- Understand the optimal approach before coding.
- Analyse Time Complexity and Space Complexity for every solution.
- Revise previous concepts regularly.
- Stay consistent—don't skip a day!

📈 Progress

- Day 1 → Day 45: Daily solutions, explanations, and optimized code.

🌟 Outcome

By the end of this challenge, I aim to become more confident in solving coding problems, perform better in technical interviews, and build a strong foundation in DSA for software engineering roles.
