# 🚀 45-Day DSA Challenge

Welcome to my **45-Day Data Structures & Algorithms (DSA) Challenge** repository! This repository documents my journey of mastering DSA through consistent daily practice. The goal is to strengthen problem-solving skills, write optimized solutions, and prepare for coding interviews, campus placements, and software engineering roles.

## 🎯 Objectives

- Solve DSA problems consistently for **45 days**.
- Build a strong foundation in Data Structures & Algorithms.
- Improve analytical thinking and problem-solving skills.
- Learn and implement optimized approaches.
- Prepare for technical interviews and competitive programming.

## 📚 Topics Covered

- Arrays

- Searching & Sorting
- Binary Search
- Recursion & Backtracking
- Linked Lists
- Stacks & Queues
- Hashing
- Trees & Binary Search Trees
- Heaps & Priority Queues
- Graphs

- Dynamic Programming

## 🛠️ Challenge Rules

- Solve **2–5 problems every day**.
- Understand the problem before coding.
- Write clean, optimized, and readable code.
- Analyze **Time Complexity** and **Space Complexity**.
- Revise previously covered topics regularly.
- Stay consistent throughout the challenge.
